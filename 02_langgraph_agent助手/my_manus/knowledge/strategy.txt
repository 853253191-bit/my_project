# 产业链逆向拆解投资策略（泛化版）

> 本文档由「策略1」「策略2」归纳而来，适用于科技/制造业等**产业链长、环节多、存在物理或工艺壁垒**的赛道。不绑定具体行业与个股，可作为 Agent 或人工投研的通用框架。

---

## 一、策略定位

### 1.1 核心思想

用**工程师思维**做产业链拆解：从**高度确定的终端需求**出发，**自下而上**还原为「必须消耗的物料与部件清单」，逐层向下挖掘，找到：

- **价值量高**或**壁垒高**的环节；
- **刚需、难替代、扩产慢**的**卡脖子**节点；
- **供需错配**尚未被定价的区间。

目标不是跟随主流机构在「已充分覆盖的大市值龙头」里卷下一季预期差，而是在**认知尚未扩散**的层级赚取**从「不知道」到「知道」的重新定价**。

### 1.2 与主流做法的差异

| 维度 | 主流机构常见做法 | 本策略 |
|------|------------------|--------|
| 方向 | 自上而下：龙头、大盘、季度业绩与估值 | 自下而上：物料清单、瓶颈环节 |
| 标的 | 大市值、高覆盖、信息透明 | 小而聚焦、低覆盖、冷门层级 |
| 信息差 | 越靠近终端越大，偏贝塔 | 越靠近底层越冷门，偏阿尔法 |
| 宏观 | 多因子、事件驱动 | **仅判断终端需求 2～3 年是否延续**，其余宏观噪音尽量不看 |
| 验证 | 卖方模型、一致预期 | 证据链 + 断供测试 + 定量缺口 |

## 二、总流程（七步）

```text
终端需求是否成立？
    ↓ 是
需求由哪些部件/子系统构成？（价值量 + 增速）
    ↓
逐层向上游拆解（比市场共识多拆 1～2 层）
    ↓
识别：卡点 / 瓶颈 / 供需错配
    ↓
不可替代性测试 + 定量分析（产能、需求、缺口、涨价）
    ↓
筛选供应商（聚焦、寡头、小市值、低覆盖）
    ↓
小仓验证 → 等催化剂 → 机构覆盖前建仓
```

## 三、第一步：终端需求门槛（唯一宏观判断）

在向下拆解之前，先回答一个问题：

> **未来 2～3 年，该终端需求（如算力扩张、某类设备放量）会不会停？**

- **会停**：不继续拆，不建仓。
- **不会停**：且存在巨头资本开支、政策或技术路线等**可引用的背书**，才进入产业链拆解。

其余宏观（利率、选举、地缘等）默认**不纳入**主逻辑，避免分散精力。

## 四、第二步：产业链拆解方法

### 4.1 还原「物理系统」

把终端产品看作一个**必须跑起来的物理系统**，列出：

1. **核心功能模块**（价值量通常最高）；
2. **互连 / 传输 / 接口**（往往第二价值量）；
3. **供电、散热、结构件、特种材料、测试与设备**等支撑环节。

对每一层问：

- 市场规模是否在变大？
- 供应商有几家？是否寡头？
- 扩产周期多长？认证与良率门槛多高？

### 4.2 拆解深度原则

- **不要停在共识层级**（例如多数人会分析到「模块/整机」，策略要求再往下：模块里的关键器件 → 器件的上游材料 → 工艺与设备）。
- **越往下往往越「脏、冷门」**，信息优势越大，但需用证据链支撑，不能凭想象。

### 4.3 三种横向延伸（同层扩散）

在纵向拆解之外，可在产业链**同一层级**做横向联想：

| 类型 | 含义 | 示例逻辑（抽象） |
|------|------|------------------|
| **同构部件** | 终端系统除 A 外还必需 B、C… | 主芯片涨 → 查服务器/系统还缺什么、何者用量随规模非线性增长 |
| **上游物料** | 某中间品已涨 → 拆其 BOM | 中间品放量 → 上游原材料/辅材谁受益、谁有卡点 |
| **替代/挤压** | 高端紧缺是否带动低端或同类 | 高端产能不足 → 低端涨价、国产替代、相邻品类估值修复 |

三种方式共用同一套：**价值量、边际变化、卡点、供需**。

## 五、第三步：识别「卡点 / 瓶颈 / 错配」

### 5.1 理想环节的四条特征

优先找**同时满足越多越好**的环节：

1. **刚需、难替代**：下游必须采购，短期无等价技术路线。
2. **寡头格局**：全球有效供应商少（理想 **< 5 家**），价格竞争弱。
3. **产能刚性**：扩产慢（理想 **> 12 个月**，工艺/设备/认证/Know-how 门槛高，新玩家短期无法复制良率）。
4. **认知空白**：机构覆盖少、叙事难懂、股价尚未充分反映逻辑。

### 5.2 供需错配

在确认「需求跳升」后，量化：

- **存量产能**（全球或主要供给国）；
- **新增需求**（由技术升级、渗透率、出货量推导）；
- **供给扩张速度**（新产能投产节奏、认证通过名单）；
- **缺口大小与持续时间**。

**需求激增 + 供给无法快速跟上** = 瓶颈投资的核心场景。

### 5.3 断供测试（不可替代性）

假设目标公司**明天停产**，依次回答：

1. 下游是否**必须改架构**才能继续生产？
2. 换供应商需要多久（认证、良率爬坡、专利）？
3. 下游是否在**囤货**（财报、库存、供应商集中度）？
4. 客户切换成本是否极高（重新设计、重跑验证、延误量产）？

若「拿掉它下游做不出产品 / 严重延期数年」，则卡点成立。

## 六、第四步：定量分析（必做）

定性链条必须落到数字，否则视为未完成研究。

### 6.1 必算指标

| 类别 | 内容 |
|------|------|
| 供给 | 当前产能、在建产能、投产时间、良率、主要厂商份额 |
| 需求 | 下游出货量、单机用量、技术升级带来的**单位用量变化** |
| 缺口 | 供需差、缺口占需求比例、预计持续几个季度/年 |
| 价格 | 历史溢价、现货/长单、涨价对毛利率、净利的弹性 |
| 公司 | 该业务营收占比、利润弹性、估值与增速匹配度 |

### 6.2 估值与情景

- 做**乐观 / 中性 / 悲观**关键假设（终端需求、份额、价格）。
- 推算未来 2～3 年营收、利润 → 套入 PE/PB/PS → 对比当前价位是否仍低估。
- 目标：在同一逻辑簇里选出**弹性最大、估值相对合理**的标的，而非泛泛「看好赛道」。

### 6.3 研究时间底线（纪律）

单票建仓前，若**系统性研究时间明显不足**（例如未读财报、未算缺口、未做排雷），应视为**未达标**，不宜重仓。深度研究本身是该策略的护城河，也是成本。

---

## 七、第五步：标的筛选标准

在「卡点环节」上，对供应商做清单（**本仓库 Agent5 仅纳入 A 股沪深主板上市公司**），优先：

1. **上市范围（硬约束）**：仅 **A 股沪深主板**；**排除**科创板（688）、创业板（300）、北交所（8 开头）及 **ST / *ST** 股票；
2. **业务高度聚焦**于该瓶颈（纯血标的优于多元化巨头的一小块业务）；
3. **市值基数相对小**，仍有认知扩散空间；
4. **尚未被主流资金充分定价**（低覆盖、低换手、叙事未出圈）；
5. 财务与治理可排雷（现金流、客户集中度、关联交易、稀释风险）。

注意：机构有合规、市值门槛与流程周期，**小票往往在逻辑兑现后才被大规模覆盖**——策略意图是在此之前完成布局。

## 八、第六步：建仓与验证节奏

| 阶段 | 动作 |
|------|------|
| **逻辑验证** | 小仓位试探；观察价格/溢价/交期是否已反映紧缺 |
| **催化剂** | 等待可被第三方验证的事件：扩产公告、客户承认短缺、行业数据、订单/毛利率变化 |
| **加仓** | 逻辑与数据相互印证后加码；理想状态是**卖方深度覆盖前** |
| **持有** | 按 3～5 年产业趋势持有，除非逻辑被证伪或估值极端透支 |

赚的是：**认知差收敛 + 供需错配定价** 的钱，不是短期情绪博弈。

---

## 九、用 AI 辅助研究（工具层）

AI **不能**替代「买什么」的结论，但可以：

1. 把拆解草稿交给模型，**专门挑漏洞**（替代路线、技术颠覆、供给响应）；
2. 列出「若要证伪本逻辑，需要哪些数据」；
3. 辅助整理 BOM、产业链层级、公开资料摘要。

原则：**用 AI 找自己的错**，而不是用 AI 直接给股票代码。

## 十、策略检查清单（Agent / 人工通用）

研究任一科技/制造主题时，可按此清单自检：

- [ ] 终端需求 2～3 年是否成立？有无可引用背书？
- [ ] 是否画出「终端 → 模块 → 器件 → 材料/工艺」至少 **3 层**拆解？
- [ ] 是否比市场共识**多拆 1 层**？
- [ ] 目标环节是否：刚需 / 寡头 / 扩产慢 / 低覆盖（满足几条）？
- [ ] 是否完成**断供测试**？
- [ ] 是否量化：产能、需求、缺口、持续时间、涨价弹性？
- [ ] 是否对比同逻辑簇内多标的估值与弹性？
- [ ] 是否排雷财报与治理？
- [ ] 是否有可观察的**验证指标与催化剂**？
- [ ] 建仓规模是否与证据强度匹配？

## 十一、风险与边界

1. **逻辑错误**：逆向链条某一环假设不成立 → 整链崩塌；必须用数据和断供测试反复校验。
2. **扩产超预期**：瓶颈可能被缓解 → 需跟踪在建产能与良率突破。
3. **技术路线切换**：底层材料或架构被替代 → 持续做替代方案监测。
4. **流动性**：小市值、低覆盖标的波动大，需匹配仓位与持有期。
5. **能力圈**：不可能覆盖所有行业；**少而精**优于全面撒网。

---

## 十二、一句话总结

> **先确认终端需求会延续 → 把产品拆成必须消耗的物料清单 → 向上下游找到「少供应商、慢扩产、难替代、需求跳升」的瓶颈 → 用数字算清缺口与弹性 → 在共识形成前布局。**

### 13.1 定价节奏与仓位纪律

| 规则 | 含义 |
|------|------|
| **~8 个月提前定价** | 多数科技主题市场会在催化剂前约 8 个月开始定价；过早（12 个月+）重仓易承受回撤与机会成本 |
| **例外：Space / Robotics / Quantum** | 这些主题市场更愿意提前定价，不必机械套用 8 个月 |
| **设备先于量产** | 设备/材料供应商收入往往**早于**终端出货量拐点——下游扩产前必须先买机台 |
| **认证甜蜜区** | H1→H2 完成产线认证、H2 次年量产放量，是中小供应商常见的「逻辑验证 → 收入兑现」窗口 |
| **少换船** | 逻辑被验证的赢家往往持续跑赢；频繁追逐新主题易 FOMO，不如让已有仓位跑完周期 |
| **多马并行** | 同一主题内选 2～3 只高弹性标的分散，而非押单一名字 |

**当前（2026 中）主题节奏参考**（随时间需更新）：

```text
Memory      — 正处 HBM3e/HBM4 瓶颈中段，龙头持续重估；HBF ~2027
Photonics   — 1.6T 可插拔「现在」；CPO Scale Out H2 2026；CPO Scale Up H2 2027
Neocloud    — 建设期；ARR 拐点常出现在 Q4 财报窗口
Glass 基板  — H2 2026 小批量；H2 2027–2028 放量（CoPoS 等）
Humanoid    — 极早期；场景专用 > 泛用；供应链主要在中日
Quantum     — 2030 商业化叙事；原型阶段不宜当长期稀释方
```

### 13.2 与框架对齐的研究方法（新增信息源）

在原有「BOM 拆解 + 断供测试」之外，实战中高频使用的**挖名渠道**：

| 渠道 | 用法 |
|------|------|
| **大报告反向读** | 高盛等机构 CPO/ASIC 等报告只列 obvious names；**未出现在报告里的供应商**往往是 hidden gem |
| **SEC 竞争对手披露** | 读 `$COHR` 等龙头 10-K 里列出的 competitors，回溯 2～3 年涨幅 |
| **贸易/海关记录** | Starlink、SpaceX 等终端的直接供应商名单，再逐家筛财务与 TAM |
| **CHIPS Act / EU 影响评估** | 政府影响分析已帮列供应商与份额（如 TOWA 模封 61%） |
| **行业展会** | Computex 等找 CPO/光电子**采样/demo 阶段**新公司，再验证是否有真实客户 |
| **地缘出口管制链** | 中国限制 A（铟、钨 WF₆、稀土…）→ 推导出日韩/西方**替代与缺口**的第三阶效应 |
| **TSMC 垂直整合** | 关注子公司（如 Xintec 测试、VisEra）是否绑定 COUPE/CoPoS/CPO 平台 |
| **韩国「国产替代冠军」** | 存储/设备环节用本土公司打破 `$KLA`/`$AMAT` 垄断的模式可复用识别 |
| **Activist / 隐蔽资产** | 控股公司持有关键子公司股权但市值未反映（如 PCB 厂持 AI 交换机 PCB 平台股份） |

**关键提醒**：新闻公开某瓶颈时，往往已是 ripple 的**偏后段**；价值在「第三阶联想」——研究 InP 基板时同步追问钨 WF₆、PGMEA 等是否被连带收紧。

### 13.3 瓶颈重估的「市场脾气」（经验法则）

1. **行业级灾难才千倍重估**：仅对 1～2 家下游供货的小上游，市场常**不 care**，除非像 `$AXTI` 那样「拿掉它整条光电子/存储链停摆」。
2. **寡头 + 专利封锁 ≈ 定价权**：CPO 检测等「90%+ 份额 + 拒绝授权竞品」环节，需求刚性、可任意加价（类比 Soitec 不授权 Shin-Etsu）。
3. **垂直整合多卡点**：单一公司控住 4 个上游 chokepoint（如 InP 基板全链）→ 西方可能掀起并购/锁产能潮。
4. **囤货/库存信号**：下游在瓶颈期囤货（如 memory hoarding）→ 既是验证也是二阶交易机会。
5. **韩国市场**：波动极大、杠杆产品扰动 `$EWY` 等指标，需单独评估是否参与。

### 13.4 2025–2026 重点瓶颈地图（抽象层）

以下为帖子中反复出现的**拆解层级**，Agent 可按终端需求向下展开，不预设具体代码：

#### A. 算力 / 互连（Photonics & Packaging）

```text
终端：AI 集群互连升级（800G → 1.6T → CPO）
  ├─ 可插拔模块：EML / CW 激光（T1: LITE/COHR/AVGO；T3: 小市值激光厂）
  ├─ CPO 架构：FAU、光引擎、连接器、热管理 Cage
  ├─ 上游材料：InP 基板、硅光/SiPho、PCB  midplane
  ├─ 检测/计量：CPO inspection 寡头环节（yield 刚需、inelastic）
  └─ 先进封装：COUPE / CoPoS、hybrid bonding、glass core 基板
```

**跨架构标的逻辑**：InP 基板、CW 激光等被 pluggable / NPO / CPO 多架构共用 → 一份研究覆盖多条升级线。

#### B. 存储（Memory Stack）

```text
HBM3e（现在）→ HBM4 量产（现在）→ HBF（~2027）
  ├─ 龙头：Samsung / SK Hynix / Micron / Kioxia / Sandisk
  ├─ 设备/材料：hybrid bonding  IR 计量、TC bonder、先进封装材料
  └─ 特种气体：WF₆（钨前驱体，DRAM/NAND 刻蚀/沉积）— 地缘出口管制第三阶
```

#### C. 被动元件 / 化合物（MLCC & 特材）

```text
MLCC 上游栈：
  BaTiO₃ 介电粉（Sakai 等）→ 高纯 Ni 粉/内电极浆料 → Dy/Y/Ho 稀土掺杂
  并行：硅电容 vs MLCC；PMIC 寡头（TI/ADI 等）；BMC（Aspeed ~70% 全球份额）
```

| 受限物项 | 下游影响 | 研究方向 |
|----------|----------|----------|

| PGMEA 等湿电子 | 光刻配套 | 日韩台小厂、短缺时的涨价弹性 |

#### E. 物理 AI / 人形（Physical AI）

#### G. 生态位与权力结构（非纯 BOM）

- **NVIDIA 造王者**：扶持 ASIC 挑战者分散 `$AVGO` 份额；Neocloud 延伸生态对抗 CSP 自研 ASIC。
- **锚定 compounders**：`$TSM` / `$AVGO` / `$MRVL` / SK Hynix 等作为底仓，高 beta 瓶颈小票做卫星。
- **地缘风险**：中东冲突 → 影响 hyperscaler 融资与 AI capex 情绪；与产业逻辑分开评估仓位。

### 13.5 标的筛选的补充启发（来自实战）

> **Agent5 落地约束**：正式 `suppliers` 输出仅含 **A 股沪深主板**；下列美股/韩股案例仅作产业链逻辑参考，不得直接作为标的代码写入报告。

| 特征 | 为何重要 |
|------|----------|
| **纯血 + 小市值 + 低覆盖** | `$SIVE` 级 CPO 激光、`$210M` 级 HBM 计量，认证前是甜蜜区 |
| **TSMC/巨头子公司** | 母公司持股 + 平台绑定 → 下行有底，上行跟 COUPE/CPO 放量 |

**反面纪律**：

- Quantum 原型期：不宜充当「长期稀释方」。
- 过早 all-in 12 个月+ 的主题：宁可小仓等 ~8 个月窗口再加码。
- 光电子短期涨幅过大时：区分「叙事透支」与「架构切换真实放量」。

### 13.6 与检查清单的增量项

在第十章清单基础上，研究科技瓶颈时**额外**自检：

- [ ] 是否查了**第三阶**地缘/出口管制 ripple（不只盯当前热点材料）？
- [ ] 是否对照大报告找**未被列名**的上游？
- [ ] 催化剂距现在约几个月？仓位是否匹配 **~8 个月定价** 节奏？
- [ ] 设备/材料环节是否**领先**终端出货量 1～2 个季度？
- [ ] 该瓶颈是「行业停摆级」还是「仅服务 1～2 客户」？预期重估幅度是否匹配？
- [ ] 跨架构（pluggable / CPO / NPO）能否一份研究覆盖多条线？
- [ ] 韩国/小市值标的是否单独评估波动与流动性？（**Agent5 仅 A 股主板小市值**）
