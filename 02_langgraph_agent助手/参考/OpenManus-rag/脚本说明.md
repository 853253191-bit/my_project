# OpenManus-rag 脚本说明

本目录为 [OpenManus](https://github.com/FoundationAgents/OpenManus) 的课程定制副本（**rag** 侧重**知识库增强**与**URL 直达策略**，减少复杂页面交互）。项目安装与上游说明见 [README_zh.md](./README_zh.md)。

## 三版本对比（rag / cy / gui）

三个目录均为同一 OpenManus 框架的课程分叉，入口脚本相同，差异在知识注入方式与浏览器工具实现。

| 对比项 | **OpenManus-rag**（本目录） | [OpenManus-cy](../OpenManus-cy/脚本说明.md) | [OpenManus-gui](../OpenManus-gui/脚本说明.md) |
|--------|---------------------------|---------------------------------------------|-----------------------------------------------|
| 核心思路 | 知识库注入 Prompt + URL 直达 | Crawl4AI 网页抓取 | GUI-Plus 视觉操作 |
| 知识来源 | `knowledge/*.txt` 加载进 system prompt | 无本地知识库 | 无本地知识库 |
| 浏览器增强 | `element_classifier` 元素语义分类 | 标准 browser-use | `gui-plus` 截图点击/输入 |
| 独有模块 | `url_helper.py`、`element_classifier.py` | `crawl4ai.py` | 增强版 `browser_use_tool.py`（~1650 行） |
| 机票查询策略 | **构造携程 URL 直接跳转**（知识库教 Agent） | 常规页面操作 | 视觉/智能 click 操作日历 |
| 教程脚本 | `scripts/tests/test_url_helper.py` | 无额外教程 | `scripts/tutorial/gui-plus使用.py` + 7 个浏览器测试 |
| 适用场景 | 有固定 SOP 的流程型任务 | 通用网页抓取分析 | 复杂 GUI、动态日历等 |

```
                    OpenManus 基础框架
                           │
         ┌─────────────────┼─────────────────┐
         ▼                 ▼                 ▼
    OpenManus-rag     OpenManus-cy      OpenManus-gui
    知识库 + URL       Crawl4AI         GUI-Plus 视觉
    绕过复杂 UI        内容抓取          操作复杂 UI
```

## RAG 机制说明（本版本核心）

本版本的「RAG」并非向量数据库检索，而是 **Prompt 知识注入**：

### 1. 知识库目录 `knowledge/`

在 `knowledge/` 下放置 `.txt` 文件，启动时由 `app/prompt/manus.py` 的 `_load_knowledge_base()` 自动读入，拼接到 `SYSTEM_PROMPT`：

```
=== 知识库参考 ===
以下是常见场景的处理方法，请优先参考：
--- travel_tools.txt ---
（携程 URL 格式、城市代码表等）
=== 知识库结束 ===
```

**扩展知识库**：在 `knowledge/` 新增 `.txt` 即可，重启 Agent 生效。

### 2. URL 帮助工具 `app/tool/url_helper.py`

将自然语言机票查询解析为携程直达 URL，绕过日历选择器等复杂交互：

```python
from app.tool.url_helper import build_ctrip_flight_url_from_query

url = build_ctrip_flight_url_from_query("1月30日从上海到北京的机票")
# -> https://flights.ctrip.com/online/list/oneway-sha-pek?depdate=2026-01-30&...
```

Agent 通过知识库学会该策略后，可用 `browser_use` 的 `go_to_url` 直接打开结果页。

### 3. 元素分类器 `app/tool/element_classifier.py`

在 `browser_use_tool.py` 中对页面 DOM 元素做语义分类（DATE、INPUT、BUTTON、CALENDAR 等），帮助 LLM 更准确选择交互目标。

## 与其他版本如何选型

| 你的任务 | 推荐版本 |
|----------|----------|
| 流程固定、可总结为文档（机票、订票 SOP） | **OpenManus-rag** |
| 抓取网页内容、转 Markdown 给 LLM | OpenManus-cy |
| 必须点击日历、弹窗等复杂 GUI | OpenManus-gui |

三者 `main.py` 入口相同，但 **不要混用不同目录下的 `app/` 代码**。

## 常见问题

1. **Agent 仍去点日历而不走 URL**：检查 `knowledge/travel_tools.txt` 是否存在，或加强 prompt 中的示例。
2. **日期解析错误**：`url_helper` 对「1月30日」默认当前年，已过年份会自动用明年。
3. **浏览器工具报错**：执行 `playwright install`。
