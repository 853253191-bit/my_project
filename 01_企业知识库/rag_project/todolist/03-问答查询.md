实现 **跨文档检索 → bge-reranker 重排 → qwen-turbo-latest 结构化问答 → Streamlit Web 界面**，使用户能以自然语言提问并获得带引用的中文答案。

## 4. 详细任务清单

### T1 跨文档检索（retrieval.py）

#### T1.1 实现 retrieve_all()

- [ ] 新增方法签名：

```python
def retrieve_all(
    self,
    query: str,
    per_index_top_n: int = 5,
    global_top_k: int = 20,
) -> list[dict]:
    """
    遍历 vector_dbs/*.faiss，合并检索结果。
    返回按相似度降序的 chunk 列表。
    """
```

- [ ] 实现步骤：
  1. `_embed_query(query)` — 使用 qwen2.5-vl-embedding 纯文本融合向量, dim=1024
  2. 遍历 `vector_dbs/` 下每个 `{sha1}.faiss`
  3. 对每个索引 `search(query_vec, per_index_top_n)`
  4. 根据 faiss id 映射回 chunk（从 `chunked_reports/{sha1}.json`）
  5. 合并所有结果，按 score **全局降序**排序
  6. 取 top `global_top_k` 条

#### T1.2 返回结构

- [ ] 每条结果 dict 必须包含：

```python
{
    "score": 0.85,           # 向量相似度
    "text": "...",
    "page": 12,
    "chunk_index": 3,
    "doc_id": "2021-KS-0017",
    "doc_title": "D06单元控规调整",
    "file_name": "...",
    "sha1": "...",
}
```

#### T1.3 禁用公司名路由

- [ ] 不再调用 `retrieve_by_company_name()`
- [ ] 删除或绕过 `_extract_companies_from_subset()` 在检索前的过滤
- [ ] `HybridRetriever` / BM25 本版本不使用（SPEC v1）

#### T1.4 Parent Document Retrieval（可选增强）

- [ ] 若 `RunConfig.parent_document_retrieval=True`：
  - 命中 chunk 后，从 `02_merged_reports` 取**整页** text 替换 chunk text
  - 保留原 chunk 的 page、doc metadata
- **验收**：
  - query =「D06 单元控规调整用地性质」→ top 结果 doc_id 含 `2021-KS-0017`
  - query =「东部新城核心区空间结构」→ 可能命中 `2021-KS-0027`

### T2 bge-reranker 重排（reranking.py）

#### T2.1 改造为 TextReRank API

- [ ] 删除/禁用原 LLM（qwen-turbo）重排逻辑
- [ ] 实现 `rerank(query, candidates, top_n)`（SPEC 6.1.2）：

```python
import dashscope

response = dashscope.TextReRank.call(
    model="bge-reranker",
    query=query,
    documents=[c["text"] for c in candidates],
    top_n=top_n,
)
# 解析 results，按 index 映射回 candidates metadata
```

- [ ] 将 `relevance_score` 写入结果 `rerank_score` 字段
- [ ] 按 rerank_score 降序返回 top_n 条（默认 10）

#### T2.2 保留 metadata 映射

- [ ] TextReRank 返回的 `index` 对应 candidates 列表下标
- [ ] 重排后每条仍含 doc_id、doc_title、page、text
- [ ] 空 candidates 时直接返回 `[]`

#### T2.3 RunConfig 开关

- [ ] `use_reranking=True` 时调用 rerank；False 时取向量 top_n
- [ ] `rerank_sample_size=20`：最多送 20 条候选进 rerank
- **验收**：
  - 同一 query，开启 rerank 后 top-1 与纯向量 top-1 可能不同
  - rerank 失败时降级为向量排序（可选，或直接报错）

```
1. retrieval_results = retriever.retrieve_all(question)
```

## 9. 常见问题

| 问题 | 处理 |
|------|------|
| 答案幻觉页码 | 加强 `_validate_references` |
| rerank API 报错 | 检查 model 名 `bge-reranker` 与账户权限 |
| 检索结果不相关 | 检查 image_paths 是否正确关联；确认多模态索引已 rebuild |
| Streamlit 找不到 vector_dbs | 确认 cwd 为 rag_project 根目录启动 |
| QPM 超限 | parallel_requests=1，评测题间隔 sleep |
