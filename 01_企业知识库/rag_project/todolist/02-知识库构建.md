### T2 改造 ingestion.py（VectorDBIngestor）

#### T2.1 实现 embed_chunk 融合向量

- [ ] 新增 `embed_chunk(text: str, image_paths: list[str], data_root: Path) -> list[float]`：

```python
import dashscope
from pathlib import Path

def _to_file_uri(path: Path) -> str:
    return path.resolve().as_uri()  # file:///...

def embed_chunk(text: str, image_paths: list[str], data_root: Path) -> list[float]:
    dashscope.api_key = os.getenv("DASHSCOPE_API_KEY")
    mm_input = [{"text": text}]
    if image_paths:
        img_path = data_root / image_paths[0]
        mm_input.append({"image": _to_file_uri(img_path)})
    response = dashscope.MultiModalEmbedding.call(
        model="qwen2.5-vl-embedding",
        input=mm_input,
        parameters={"dimension": 1024},
    )
    emb = response.output["embeddings"][0]["embedding"]
    assert len(emb) == 1024
    return emb
```

- [ ] **逐 chunk 调用**（MultiModalEmbedding 不支持像 TextEmbedding 那样大批量纯文本）；用 `tqdm` 显示进度
- [ ] 使用 `tenacity` 对限流/网络错误重试
- [ ] `image_paths` 为空时仅传 `{"text": text}`

#### T2.2 构建 FAISS 索引

- [ ] 使用 **1024 维** 索引（与 RAG-cy 一致可用内积 + L2 归一化）：

```python
import faiss
import numpy as np

dimension = 1024
index = faiss.IndexFlatIP(dimension)  # 内积，向量需 L2 normalize

vectors = np.array(embeddings, dtype=np.float32)
faiss.normalize_L2(vectors)
index.add(vectors)
```

- [ ] 保存至 `databases/vector_dbs/{sha1}.faiss`
- [ ] 同步保存 chunk 索引映射（RAG-cy 通常将 chunk 顺序与 FAISS id 对应，保存在 sidecar JSON 或 chunked_reports 中）

#### T2.3 索引 sidecar 元数据

- [ ] 每个 `{sha1}.faiss` 旁写入 `{sha1}.meta.json`（或在 chunked JSON 中记录）：


- **验收**：meta 中 `embedding_dimension` 恒为 1024

#### T2.4 process_reports 批量建库

## 8. 常见问题

| 问题 | 处理 |
|------|------|
| dimension 不等于 1024 | 检查 `parameters={"dimension": 1024}` |
| 图片路径错误 | 使用 `Path.as_uri()` 生成 file:/// URI |
| 建库 API 调用过多 | 逐 chunk 调用属正常；注意 DashScope QPM，加 sleep/重试 |
| faiss 搜索无结果 | 确认 query 向量做了 L2 normalize |
| DashScope 429 限流 | 减小 batch_size，增加重试间隔 |
| 旧 v1 索引残留 | 删除 vector_dbs/ 后全量 rebuild |
