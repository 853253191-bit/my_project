# 阶段一：文档预处理

> **依据文档**：[spec/SPEC.md](../spec/SPEC.md) v1.2  
> **编码原则**：以 SPEC 为权威来源；本清单为逐步实施指南。  
> **预估工作量**：2–3 天  
> **下一阶段**：[02-知识库构建.md](./02-知识库构建.md)

---

## 1. 阶段目标

将 **10 份规划类 PDF** 处理为带 **文本 + 页图路径（image_paths）** 的分块 JSON，供 **qwen2.5-vl-embedding** 多模态建库使用。本阶段**不涉及**向量化与 FAISS 建库。

**核心产出：**

| 产出 | 路径 |
|------|------|
| 文档注册表 | `data/项目知识库/subset.csv` |
| Docling 解析结果 | `data/项目知识库/debug_data/01_parsed_reports/{sha1}.json` |
| 规整后按页 JSON | `data/项目知识库/debug_data/02_merged_reports/{sha1}.json` |
| Markdown 抽查导出 | `data/项目知识库/debug_data/03_reports_markdown/*.md` |
| 页图 PNG | `data/项目知识库/debug_data/04_page_images/{sha1}/page_*.png` |
| 分块 JSON | `data/项目知识库/databases/chunked_reports/{sha1}.json`（含 `image_paths`） |

## 8. 常见问题

| 问题 | 处理 |
|------|------|
| Docling 首次下载慢 | 提前运行 `download-models`，或使用 GPU 环境 |
| subset doc_id 与 SPEC 不一致 | 对照 3.2.4 表手工修正 CSV 后重跑 |
| process-reports 触发向量化 | 拆分 CLI，本阶段只跑到 chunk_reports |
| 中文乱码 | 确保脚本与 JSON 均为 UTF-8 编码 |
