# 暂存 TXT 归档为 Markdown

将 `暂存文件` 目录下单个 `.txt` 改写成 Obsidian 可用的 Markdown 笔记。

## 改写要求

1. **保留原意**：不删除关键信息，不编造原文没有的事实、版本号或数据。
2. **结构化**：用 `#` / `##` / `###` 分层；长段落拆成列表；表格类内容可保留 Markdown 表格。
3. **中文输出**，UTF-8，不要输出 HTML。
4. **只输出 Markdown 正文**：不要包裹在 ```markdown 代码块里，不要写「以下是整理结果」等前言。
5. **标题**：若原文无明确标题，从文件名或首句提炼一个 `#` 一级标题。
6. **风格**：学习笔记风格，简洁可读，比原文略整理即可，不要扩写成超长专题。

## 范围外

- 不要修改路径、不要提及暂存目录或归档流程。
- 不要创建备份文件说明。
